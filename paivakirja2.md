# Oppimispäiväkirja: Hajautettu git

__Mikä osion tehtävissä oli vaikeaa ja mikä helppoa? Mikä auttoi minua oppimaan? Miten selvitin esteet, jotka vaikuttivat tehtävän suorittamiseen?__

Vaikeaa oli välillä se, että olenko oikeassa haarassa, mutta se selvisi aina.
Githubin linkittäminen oli helppoa, olen sen joskus aikaisemmin joutunut tekemään. Taas git statuksen käyttö joka välissä
auttoi oppimaan. Esteet selvitin lukemalla ohjeet uudestaan ja tarkistamalla kirjoitusvirheet. 

## Osiossa käyttämäni Git-komennot

| Komento | Kuvaus |
| --------| ------ |
| git remote add origin | lisää github repositorion etärepositorioksi nimellä origin |
| git remote -v | näyttää etärepositorion osoitteen |
| git push -u origin main | vie paikallisen main haaran githubiin |
| git push -u origin new-feat | vie uuden new-feat haaran githubiin |
| git fetch | hakee etärepon uudet tiedot yhdistämättä niitä |
| git switch origin/new-feat | tarkastelee etärepon haaraa |
| git merge origin/new-feat | yhdistää etärepon muutoksen paikalliseen haaraan |
| git push origin main | vie paikallisen main haaran muutokset githubiin |
